# Brand

**Name:** Thermogeist. **Tagline:** "Calm radiator control". **Story hook:** "From poltergeist
to thermogeist" – today's thermostats rattle and slam valves; Thermogeist makes them calm and
explains itself.

## Logo

A radiator thermostat seen from the side. The display is a dark visor with two mint eyes – a
subtle nod to a friendly house spirit without putting a ghost in focus. Amber status LED stands
for warmth.

| ID | Requirement | Status |
|---|---|---|
| BRD-001 | The mark has light fills with a dark outline, so it stays visible on white, grey, coloured and dark backgrounds. | implemented |
| BRD-002 | Files: `brand/icon.svg` (dark tile), `brand/icon-transparent.svg`, `brand/logo.svg` (dark), `brand/logo-light.svg` (transparent, for light backgrounds), plus PNG exports at 256/512 px (icons) and 640 px (logos). | implemented |
| BRD-003 | All brand files are generated by `scripts/build_brand.py`; edits are made there, never in the generated files. | implemented |
| BRD-004 | Wordmark `thermogeist_` in JetBrains Mono with the underscore as a cursor in mint. | implemented |
| BRD-005 | For the final version, convert the wordmark text to outlines so it does not depend on installed fonts. | planned |
| BRD-006 | Submit icon and logo to the Home Assistant brands repository. | rejected (replaced by BRD-007) |
| BRD-007 | The integration ships its own brand images in `custom_components/thermogeist/brand/` (`icon.png`, `icon@2x.png`, `logo.png`, `logo@2x.png`, `dark_logo.png`, `dark_logo@2x.png`), which Home Assistant 2026.10 serves directly. Generated by `scripts/build_brand.py`. | implemented |
| BRD-008 | The READMEs show `brand/logo.png` (logo on its own dark card), because the HACS view inside Home Assistant ignores light/dark image switching (`<picture>`); a transparent logo would be invisible on one of the two backgrounds. | implemented |
